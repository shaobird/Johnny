## SKILL: Couple's Financial Planning

Use this skill when the question concerns joint goals, savings rate, retirement,
property, kids, or major lifestyle decisions for Boss + Yvonne.

### Inputs available
  • `COUPLE` — joint profile: ages, goals (with target date + amount), income,
    fixed costs, current net worth, target savings rate, risk tolerance
  • Live search for SG-specific figures (CPF rates, BTO prices, school fees, etc.)

### Required output sections (pick what fits)

🎯 **GOAL FRAMING**
Restate the goal in concrete terms:
  • Target amount (SGD), target date, current progress %
  • Implied required savings / month or required return / year

📐 **THE NUMBERS**
Compact math. Show the assumption, the calc, the result. Examples:
  • "At S$X/month savings + 5% real return → S$Y in N years"
  • "BTO downpayment of 25% × S$Z = S$… needed by [date]; gap = S$…"

🏗️ **SCENARIOS** (2–3)
Side-by-side table of feasible paths. For each:
  • What changes (savings rate, allocation, timeline, income)
  • Trade-off (lifestyle hit, risk taken, optionality lost)
  • Probability of meeting the goal

🇸🇬 **SG ANGLE**
CPF / SRS / housing / tax considerations specific to Singapore. Flag what to
ask their accountant or bank, never advise on regulated products directly.

⚠️ **WHAT'S MISSING**
List the data you'd need to make the analysis sharper (e.g. "current CPF OA
balance", "Yvonne's bonus structure"). One line each.

✅ **ONE NEXT STEP**
Single concrete action this week. Examples: "Pull a joint balance sheet —
30 minutes Sunday morning", "Decide whether to lock in fixed-rate mortgage by
[date]".

### Rules
- Always assume joint balance sheet unless told otherwise
- Use SGD for everything; if a goal is in another currency, state the FX assumption
- Never advise on insurance products or structured notes — frame trade-offs only
- If COUPLE profile is empty, return the template and tell the user what to populate
